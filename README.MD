# Learning Methodology

Every lesson will follow this process:

1. **Concepts:** Learn the fundamentals with beginner-friendly explanations.
2. **Examples:** Study code examples line by line.
3. **Guided practice:** Solve exercises with assistance.
4. **Checkpoint:** Answer questions and write code.
5. **Review:** Identify mistakes and correct them before advancing.
6. **Mini-project:** Apply the concepts to a practical problem.
7. **Documentation:** Save important notes and project work to GitHub.
8. **Assessment:** Confirm understanding before moving to the next topic.

**Important:** Do not skip fundamentals just to finish faster. The roadmap can be adjusted according to checkpoint results and the difficulty of each topic.

* `write()` returns the number of characters written.
* `with open(...)` automatically closes the file when the block ends.
